# my-operating-system
My Operating System (Under Development)
This is an operating system project being developed from scratch. Currently, the source code is ready to be explored, but due to hardware limitations (RAM), I haven't been able to run tests locally in a virtual machine.

🚀 Goal

The goal is to build a functional kernel and learn about low-level processing, interrupts, and memory management.

🛠 Compilation Requirements

If you'd like to help me test the code, you'll need:

• Compiler: GCC Cross-Compiler (i686-elf)

• Assembler: NASM

• Emulator: QEMU or VirtualBox

📬 Collaboration

If you manage to compile and run it, please let me know! Any bug reports or suggestions are welcome.
